# Video Factory Foundation

このフォルダは将来の動画自動生成エンジンとYouTube / Instagram / TikTok / X動画投稿をつなぐための**受け渡し仕様だけ**を定義します。

## 現在の状態

- 動画生成: **未実装**
- 自動レンダリング: **未実装**
- 音声生成: **未実装**
- 外部投稿: **このフォルダからは実行しない**
- 目的: 将来どの生成方法を採用しても、同じMP4仕様でSNS投稿側へ渡せるようにする

## 標準出力

- MP4
- 1080 x 1920
- 9:16
- H.264
- AAC
- 30fps
- 推奨30〜60秒
- 上限180秒
- 著作権確認済み素材のみ
- 初回YouTubeアップロードはprivate

## 役割分離

1. 企画層: テーマ、台本、CTA、媒体別文章
2. 生成層: 将来実装。MP4を作る
3. 検査層: 縦横、長さ、ファイル形式、音声、権利メモを確認
4. 投稿層: youtube_auto / x_auto / social_auto

生成方式を後から変更しても、3と4を作り直さない構成にする。
